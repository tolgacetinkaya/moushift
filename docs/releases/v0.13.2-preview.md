# Clickloom 0.13.2 preview

- Driverless Click Circle trigger from a source-identified standard mouse button. Each mouse uses its own existing profile and the foreground application's Circle.
- Enable Circle now works with the built-in Raw Input observer; optional exclusive remapping setup is no longer a prerequisite for Circle observation.
- Original trigger input is retained. Other saved button actions, wheel triggers, anonymous keyboard triggers and learned custom HID drafts remain inactive in driverless mode.
- Fixed a physically observed Raw Input/mouse-hook delivery race that could immediately dismiss a newly opened Circle and make reopening appear broken.
- Added a bounded developer-only mouse/Circle event trace to distinguish input edges and close causes without recording keyboard text, movement or raw device paths.
- No driver, extra package, manufacturer-specific protocol, theme or profile migration introduced.

Local checks: 32 Core tests, 50 Windows tests, offscreen Circle/editor/folder/drag/device checks in the existing themes. Physical Corsair opening was observed before the race fix; physical acceptance of the fixed version is reported separately in the local delivery record.
