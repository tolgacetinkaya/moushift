# Moushift 0.14.6 preview

- Replaces the left-side vector sketch with original graphite side artwork matching the existing top view. Top artwork, stored markers, themes and per-device assignments are preserved.
- Introduces the Moushift M/cursor mark in the header, tray, window and executable icon. SVG, PNG and multi-resolution ICO assets are included.
- Adds exact-source horizontal wheel Circle triggers. Small deltas accumulate; repeats are coalesced, and the trigger's hook packet cannot close its own Circle.
- Original middle clicks and horizontal scrolling still pass through in driverless mode. See [the suppression comparison](../INPUT_SUPPRESSION_RESEARCH.md); no new package, driver or global suppression was added.

Validation: Release build, 32 Core and 53 Windows fixture tests; offscreen light/dark WPF navigation and embedded learning validation. No physical tilt or suppression acceptance is claimed. Existing application settings were not edited.
