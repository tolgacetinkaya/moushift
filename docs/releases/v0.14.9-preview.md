# Moushift 0.14.9 preview

Assigned middle buttons now replace the normal desktop middle click when opening Click Circle. Each cycle uses its actual Raw Input mouse and existing foreground-app profile. Unassigned middle clicks are forwarded as tagged synthetic input; they do not inherit another mouse's Circle. Other trigger buttons and horizontal scrolling retain their original behavior.

The middle-button gate preserves native holds across concurrent mice, profile edits and pause, cleans up owned output on disconnect/shutdown, and pauses interception if source delivery stalls. Raw Input games, software rejecting synthetic input and higher-integrity targets are not covered by this desktop suppression behavior.

Window/taskbar, tray and executable icons now use the same neon mint (`#45FFBA`) as the exported logo assets. The approved M/star geometry, themes, saved assignments and device profiles are unchanged. No dependency, driver or vendor adapter was added.
