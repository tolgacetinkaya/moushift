# Moushift 0.14.10 preview

- Removed Teach a button, the listening workspace and its preview entry points.
- Action library categories start collapsed in both System Actions and Circle Actions. Searching expands matching categories; clearing the search collapses them again.
- Moved Back to buttons to the top-left of the Circle editor, keeping the unsaved-changes confirmation.
- Preserved previously saved learned input identities, drawing positions, assignments and per-mouse/application profiles. No settings reset or migration.
- Standard button selection, Click Circle, top/left mouse views and both themes remain available.
- Updated help and setup text to describe middle-click replacement accurately.

Download the Windows x64 portable ZIP, extract the complete folder and run Moushift.exe. The .NET and Windows Desktop runtimes are included in release packages.
