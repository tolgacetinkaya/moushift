# Moushift 0.14.1 preview

Clickloom is now Moushift. The title bar, tray menu, executable and portable archive use the new name.

Existing mouse assignments, device/application profiles and appearance are preserved in the existing `%LOCALAPPDATA%/Clickloom` data directory. The `CLICKLOOM_DATA_DIR` development override and the single-instance identity remain compatible with previous local builds. No settings migration or reset is required.

- Run `Moushift.exe`, or build locally and use `Start-Moushift.cmd`. The old launcher forwards to the new one.
- Side-by-side mouse gallery and selected-device inspector, light/dark appearance, Click Circle folders and per-application profiles are retained.
- Driverless Circle still observes five standard buttons from the exact source mouse. Original clicks still reach Windows. Other remapping and firmware-only controls retain their documented limitations.

This preview targets Windows and requires the .NET 10 Desktop Runtime. Fixture/offscreen checks are separate from physical device acceptance. No additional package or driver is installed by the rename.
