# Moushift 0.14.12 Preview 1

- Turn Click Circle and button assignments on or off together with **Mouse actions**. Moushift remembers the setting across restarts and waits for a connected mouse when needed.
- Assign a keyboard shortcut to Back or Forward in driverless mode. For example, Back can send Alt+Tab without navigating back in the browser. Each mouse keeps its own bindings.
- Customize a Circle with reusable actions, directional gestures, portable layouts and animated per-item outlines.
- Use the mouse model reported by Windows or identified in the receiver name. When a dock exposes only its own name, you can name the mouse in its device settings.

Extract the Windows x64 ZIP and run `Moushift.exe`. It includes the .NET desktop runtime. Your existing assignments and profiles load from their usual location.
