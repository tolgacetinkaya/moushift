# Moushift 0.14.3 — selected mouse navigation

- Devices opens the complete side-by-side gallery without a right settings panel or an empty reserved column.
- Clicking anywhere on a mouse card opens only that mouse's drawing in the center and its settings on the right. Clicking the artwork and clicking the title now follow the same path.
- **All mice** and **Devices** return to the full-width gallery and clear the UI selection. Saved assignments and application profiles are preserved.
- Battery badges appear below each mouse and in its detail screen. Windows-reported byte percentages are read without vendor commands; unavailable, invalid or conflicting values display **Battery unavailable**. This does not claim charging state or confirm mouse power. Many USB receivers do not expose a generic battery percentage.
- Click Circle still edits the selected mouse inside the main workspace; returning to buttons restores its single-mouse view.

Download `Moushift-0.14.3-win-x64.zip`, extract the entire folder and run `Moushift.exe`. The Windows x64 package includes .NET and Windows Desktop runtimes; no separate .NET installation is needed.

Driverless Circle still lets the original trigger click through, and no driver or extra package is installed. Automated checks cover gallery/detail/back transitions, battery ranges and identity isolation, panel widths, profile preservation, Circle hosting and both themes. They do not replace physical mouse acceptance.
