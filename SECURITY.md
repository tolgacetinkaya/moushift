# Security and privacy

Do not file public issues containing credentials, private profiles, device serials or unreviewed captures. If a security issue includes sensitive information, use the repository's private vulnerability reporting feature when available; otherwise open a minimal issue asking the maintainer for a private reporting channel without disclosing the details.

The preview supports the current 0.12 source line on a best-effort basis. There is no code-signing or security-response SLA. No driver or vendor binary is included. Releases should be obtained from the project repository and checked against their SHA-256 checksum.
