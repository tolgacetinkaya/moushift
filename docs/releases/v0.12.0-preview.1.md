# Clickloom 0.12.0 Preview 1

First proposed public source preview of the mouse/Circle workspace.

- Generic HID capability discovery without vendor/model-specific protocol adapters.
- Explicit button learning with two-press confirmation and manual drawing placement.
- Connection-scoped learned identity/name/location persistence, with existing settings and themes preserved.
- Per-mouse/application Circle documents, folders, drag/drop, custom shortcuts and pointer-following drag cards.
- Windows fixture tests, offscreen WPF checks, issue forms, PR template, CI and draft-release workflow.

Important: learned custom HID assignments are inactive drafts. Live exclusive remapping still requires a configured supported interception path. Firmware-only controls may emit no learnable event. No driver, vendor binary, account data or personal profile is bundled. See `docs/KNOWN_LIMITS.md`.

The ZIP is framework-dependent and requires .NET 10 Desktop Runtime on Windows x64. Verify it with `SHA256SUMS.txt`. This is a prerelease, not a claim of universal mouse compatibility.
