# 0.14.0 preview — gallery and inspector

Devices stay side by side, with names above the approved original mouse artwork. Selecting a connection opens that mouse's settings in the persistent right inspector. There is no duplicate device directory in the sidebar.

- Light: silver-gray surfaces, white inspector and wine accent.
- Dark: charcoal surfaces and a muted rose accent, with the same layout.
- Switch appearance with the title-bar icon or Settings → Appearance. Legacy copper/pink preferences load as dark without rewriting profile files.
- Buttons and Click Circle tabs use the existing per-device/application profiles. The Circle preview reflects the selected profile's actual actions.
- Selecting a button opens its existing action form in the inspector; Close returns to the button list. Button positions, learning, profile import and reset remain available in the inspector's disclosures.
- The Circle edit/preview controls remain accessible at short window heights. At those heights the radial preview is available on the Click Circle tab.
- Only current Windows connections appear in the gallery. Receiver presence and recent input remain separate; a receiver does not prove that a wireless mouse is powered on. Disconnection removes the connection without deleting saved profiles.

No input-routing behavior, manufacturer profile, firmware setting, driver or dependency was changed. Driverless Circle retains its original-input limitations and outside-left-click dismissal. This release does not repair physical double clicking.

Validation: 32 Core and 50 Windows checks; isolated offscreen WPF gallery/inspector, per-mouse assignment isolation, application profiles, disconnection/reconnection, live light/dark persistence, Circle folders/drag presentation, HID learning and profile-byte preservation. Visual comparison at 1440×1024 and compact capture at 1130×760. Physical device interaction with this UI release has not been repeated.
