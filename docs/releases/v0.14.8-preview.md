# Moushift 0.14.8 preview

Replaces rose selection accents with neon mint in the dark theme and deeper green accents in the light theme. Navigation, primary buttons and Click Circle selections use 75% transparent fills, with opaque text and outlines for readability. Backgrounds and the approved logo geometry are unchanged.

Fixes horizontal Circle repeat suppression being reset when an unrelated mouse connects or disconnects. Only removed or reassigned input sources now lose their pending wheel state.

Existing settings, assignments and per-device profiles are preserved. No dependency or driver was added. Driverless mode still forwards original button/scroll actions; this release does not claim exclusive suppression or new hardware support.
