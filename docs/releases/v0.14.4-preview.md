# Moushift 0.14.4 — learning inside the workspace

- **Teach a button** is a clearly styled button below the selected mouse drawing.
- Learning opens inside the main window. Back, navigation, save and quit all release the temporary listener; there is no second learning window.
- Fixed an immediate-stop bug: any Raw Input device-change notification previously disposed learning, including arrival notifications after registration. Arrival and unrelated-removal notifications now leave learning active. Removing the selected mouse's input stops it with a retry message.
- **Rescan inputs** refreshes HID discovery. A reconnect refreshes the selected connection instead of reusing old interface paths. Standard learning can still work when optional HID capabilities are unavailable.
- Bluetooth battery lookup also checks Windows' Bluetooth device-node cache. A local read returned **60% for MX Master 4**; the Corsair receiver and Razer dock still did not expose a percentage through these generic Windows properties. No vendor commands or charging-state guesses are used.

## Try learning

Select the mouse, click **Teach a button**, choose a point on the drawing, click **Listen for button**, then press and release the same physical button twice. Save its name and location. Use a standard back/forward button for the first check; firmware-only DPI/sniper buttons still cannot be learned if no accessible input is emitted.

Learning and live remapping remain separate capabilities. Per-mouse profiles, existing bindings and appearance are preserved; the app remains paused after learning.

## Validation and download

Core/Windows regression tests and isolated WPF checks exercise notification filtering, repeated learning, source isolation, reconnect, embedded layout and both themes. A local hidden message-only-window probe kept the Razer input capture active across registration arrival notifications without injecting input. Physical button presses still need user acceptance.

Download `Moushift-0.14.4-win-x64.zip`, extract the complete folder and run `Moushift.exe`. The .NET/Windows Desktop runtimes are included. No driver or additional package is installed.
