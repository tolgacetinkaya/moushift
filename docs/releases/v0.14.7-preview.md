# Moushift 0.14.7 preview

Replaces the exploratory cursor logo with the approved star-cutout M across the application header, window, tray and executable. The mark retains its upper black bridge and rounded asymmetric shoulders. SVG, transparent PNG and 32/64/256 px ICO assets are generated from the same geometry; the approved reference is included in the branding guide.

Existing theme colors, settings, assignments and per-device profiles are unchanged. No dependency or driver was added. Includes the pending 0.14.5 learning/battery improvements and 0.14.6 horizontal Circle routing corrections; original clicks still pass through in driverless mode.
