# Moushift 0.14.11 preview

- Add application-specific Circles from a searchable Windows app list in the main workspace, with Refresh and Browse fallbacks.
- Clarify **All applications**, **Circle for**, **Switch with active app** and **Edit Circle**. Each mouse keeps its own app Circles.
- Start new app Circles from the current fallback draft, reopen existing Circles without duplication, and retain the chosen app after saving.
- Preserve assignments, themes and saved switching preferences. No new dependencies or drivers.

Discovery and foreground matching are not universal: protected/unresolved apps, launchers and some hosted Store apps may require selecting the actual executable. Browser tabs are not separate applications. See [Application Circles](../APPLICATION_CIRCLES.md).

Automated validation covers scoped drafts, persistence, inherited triggers and picker selection, plus the existing Windows input suites and offscreen UI checks. Live hardware/application switching requires separate acceptance.
